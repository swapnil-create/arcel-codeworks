# ARCEL Codeworks — reference synthesis

## Core conclusion

The assistant and its composer are the product. Projects, research, coding tools, and comparison are supporting modes—not the homepage concept.

## Claude

- Calm sidebar and conversation surface.
- Projects are a peer to chats and hold related work.
- Creation is lightweight; opening a project still leads to a familiar chat experience.

## ChatGPT

- Blank, composer-led home.
- Recent conversations remain immediately accessible.
- Model choice and tools sit near the composer without turning the page into a dashboard.

## Perplexity

- Research is a clear intent.
- Sources are visible alongside answers.
- Provenance remains inspectable without overwhelming the response.

## Grok

- Modes are easy to switch.
- Long-running work has visible feedback and can be stopped.
- Results lead naturally into follow-up prompts.

## Prompt Arena

- One prompt runs across selected models.
- Responses can remain anonymous until the user judges them.
- Users can choose a winner, ask for an automatic judgment, or combine the strongest parts.

## ARCEL adaptation

- Chat, Research, and Code modes live in the universal composer.
- Projects appear in the sidebar and project library.
- Compare is a dedicated Prompt Arena workspace.
- ARCEL branding is limited to the official logo, palette, typography, and disciplined interface hierarchy.
